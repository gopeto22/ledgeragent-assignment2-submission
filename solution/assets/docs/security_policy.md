# Security and Data Handling Policy

## Data residency

- EU data residency is generally available for Enterprise and Enterprise Pilot workspaces.
- Starter and Pro workspaces run only in the shared multi-region environment.

## Regulated data

- Protected health information (PHI) is not supported on Starter or Pro.
- PHI workloads are allowed only on Enterprise Pilot environments with a signed BAA and explicit security approval.
- Public roadmap announcements are not sufficient evidence of production readiness; this policy is authoritative until controls are signed off internally.

## Identity and access

- SSO and SCIM provisioning are available on Enterprise and Enterprise Pilot.
- Encryption in transit and at rest applies to all plans.

## Incident posture

- Security incidents involving regulated data must be escalated to the security on-call within 15 minutes.
